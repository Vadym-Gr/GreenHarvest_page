# Green Harvest

Статична сторінка за макетом Figma на HTML, CSS та JavaScript із Vite.

## Локальний запуск

Використовуйте Node.js 22 LTS, як у GitHub Actions.

```sh
npm ci
npm run dev
```

Адресу сервера Vite показує в терміналі, зазвичай http://localhost:5173.

## Команди

- `npm run build` — production-збірка в `dist/` зі шляхом `/GreenHarvest_page/`.
- `npm run preview` — перегляд production-збірки за шляхом `/GreenHarvest_page/`.
- `npm run format` — форматування через Prettier.
- `npm run format:check` — перевірка форматування без змін.

## Структура

- `src/index.html` — головна сторінка та підключення partials.
- `src/partials/` — HTML-блоки сторінки.
- `src/css/index.css` — підключення normalizer, локальних шрифтів і стилів.
- `src/css/tokens.css` — палітра й типографіка з Figma.
- `src/css/` — загальні стилі та окремий файл кожної секції.
- `src/img/` — ресурси макета, які додаються з відповідними секціями.
- `src/main.js` — точка входу для майбутньої інтерактивності.
- `src/js/mobile-menu.js` — відкриття меню, Escape, керування фокусом і блокування фонової сторінки.

Шрифт Inter Tight (500, 600, 700) постачається локально через
`@fontsource/inter-tight`. `modern-normalize` підключено перед власними стилями.

## Адаптивність

Mobile first: гумова ширина від 320px, мобільний контейнер до 375px,
планшет від 768px, desktop від 1280px за макетом Figma та рішенням користувача.
Desktop-контейнер має ширину до 1280px із внутрішньою областю 1080px,
як у наданому макеті. Контейнери враховують padding через border-box.

## Етапи реалізації

1. Основа проєкту — готово.
2. Header, Hero та мобільне меню — готово.
3. How it works та Advertisement — готово.
4. Vegetables — готово.
5. Reviews — готово.
6. Your order та форма з перевіркою полів — готово; надсилання ще не підключене.
7. Footer — готово.
8. Фінальна перевірка — виконано; результати й обмеження в [QA.md](./QA.md).

Готові Header і Hero з ресурсами Figma та версіями фотографій x1/x2.
Меню займає весь екран на телефоні, а з 768px показує панель шириною 351px.
Воно закривається кнопкою, Escape, кліком на затемнення, вибором посилання
та при переході на desktop. Фокус залишається всередині відкритого меню.

Посилання Shop now веде до форми Your order.

Секція How it works містить три кроки замовлення та фотографію з окремими
кадруваннями для телефона, планшета й desktop у версіях x1/x2.
На desktop фотографія та інструкція розташовані у двох колонках.
Advertisement відтворює рекламний текст і зелений акцент із макета.

Секція Vegetables містить шість карток із назвами, цінами та зображеннями
макета у версіях x1/x2. Картки розташовані в одну колонку на телефоні,
дві на планшеті та три на desktop. Якір Vegetables веде до готового каталогу.

Секція Reviews містить відгуки та портрети авторів із Figma у версіях x1/x2.
Одночасно на телефоні показаний один відгук, на планшеті — два,
на desktop — три. Усі відгуки доступні через кнопки ліворуч/праворуч,
горизонтальний жест або стрілки клавіатури у сфокусованому списку.
Кнопки неактивні на відповідному краю списку; обидві неактивні, якщо всі
відгуки поміщаються. Додавання карток і зміна ширини автоматично оновлюють
стан кнопок. Якір Reviews веде до готової секції.

Your order відтворює форму та блок соцмереж із Figma, включно зі зображеннями
x1/x2. Ім’я та email обов’язкові, коментар необов’язковий. Поля мають label,
описові name, autocomplete, доступні повідомлення про помилки та стани
валідації. Дані залишаються у формі; сервер, зовнішній сервіс і збереження
заявок поки не підключені. Після перевірки прямо зазначено, що заявку не надіслано.
Без JavaScript кнопка надсилання вимкнена.

Поки використано форму в секції за макетом, без додаткової модальної форми.
Вимога ТЗ щодо окремої модальної заявки потребує узгодження.
Посилання соцмереж ведуть на головні сторінки платформ; адреси профілів
потрібно буде підставити після їх надання.

Footer містить логотип, якірну навігацію, клікабельний телефон і адресу
з макета. За погодженням користувача форма підписки не додається.
Privacy Policy та Cookie settings відтворені як текст; сторінку політики
та поведінку налаштувань cookies ще потрібно визначити.
