# Green Harvest

Статична сторінка за макетом Figma на HTML, CSS та JavaScript із Vite.

## Локальний запуск

Використовуйте Node.js 22 LTS, як у GitHub Actions.

```sh
npm ci
npm run dev
```

Адресу сервера Vite показує в терміналі, зазвичай http://localhost:5173.

## Команди

- `npm run build` — production-збірка в `dist/` зі шляхом `/GreenHarvest_page/`.
- `npm run preview` — перегляд production-збірки.
- `npm run format` — форматування через Prettier.
- `npm run format:check` — перевірка форматування без змін.

## Структура

- `src/index.html` — головна сторінка та підключення partials.
- `src/partials/` — HTML-блоки сторінки.
- `src/css/index.css` — підключення normalizer, локальних шрифтів і стилів.
- `src/css/tokens.css` — палітра й типографіка з Figma.
- `src/css/` — загальні стилі та окремий файл кожної секції.
- `src/img/` — ресурси макета, які додаються з відповідними секціями.
- `src/main.js` — точка входу для майбутньої інтерактивності.

Шрифт Inter Tight (500, 600, 700) постачається локально через
`@fontsource/inter-tight`. `modern-normalize` підключено перед власними стилями.

## Адаптивність

Mobile first: гумова ширина від 320px, мобільний контейнер до 375px,
планшет від 768px, desktop від 1440px згідно з ТЗ.
Desktop-контейнер має ширину до 1280px із внутрішньою областю 1080px,
як у наданому макеті. Контейнери враховують padding через border-box.

## Етапи реалізації

1. Основа проєкту — готово.
2. Header, Hero та мобільне меню.
3. How it works та Advertisement.
4. Vegetables.
5. Reviews.
6. Your order та форми.
7. Footer.
8. Фінальна перевірка.

Зараз сторінка містить лише каркас із заголовком макета. Коментарі в partials
і CSS позначають майбутні етапи, а не завершені секції.

Після кожного етапу робота зупиняється для самостійного відправлення змін
користувачем на GitHub. Наступний етап починається лише за його командою.
Workflow виконує збірку після push у main та публікує dist у gh-pages;
для доступності сайту потрібно вибрати цю гілку в налаштуваннях GitHub Pages.

## Відомі технічні зауваження

На першому етапі npm audit повідомив про 11 вразливих пакетів у наявному
ланцюжку інструментів, зокрема Vite, esbuild і glob. Оновлення інструментів
та повторну перевірку сумісності потрібно виконати окремо.
