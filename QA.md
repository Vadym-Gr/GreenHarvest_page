# Фінальна перевірка Green Harvest

Дата: 14 жовтня 2026 року.

Перевірено локальну production-збірку в Chromium на Windows за шляхом
`/GreenHarvest_page/`. Це перевірка підготовленої збірки, а не результат
публікації на GitHub Pages.

## Результати

- Перевірені ширини: 320, 360, 375, 390, 600, 767, 768, 1024, 1280, 1439,
  1440 та 1920 px. Горизонтального переповнення сторінки немає.
- Зображення та шрифти завантажуються; тимчасових адрес Figma в ресурсах
  сторінки немає. Перевірено вибір фотографій x2 на телефоні, планшеті й desktop.
- Усі внутрішні якорі мають цілі; дубльованих id немає. Перевірені переходи
  з Footer, логотипа та мобільної кнопки Shop now.
- Меню перевірено на 320×568, 375×812, 768×1024 та 844×390: фокус,
  Tab/Shift+Tab, Escape, вибір посилання, блокування фону й перехід на desktop.
- Карусель відгуків перевірено з трьома та сімома картками: крайні позиції,
  стрілки клавіатури, неактивні кнопки, зміна ширини та кількості карток.
  Додаткові картки створювалися лише в браузері під час перевірки.
- Форма перевіряє порожні поля, ім’я з пробілів та некоректний email;
  переводить фокус на перше помилкове поле, показує пояснення й зберігає дані.
  Перевірка валідної форми не надсилає дані та прямо повідомляє про це.
- Без JavaScript кнопка форми не надсилає дані, а відгуки доступні у списку
  з горизонтальним прокручуванням.
- Автоматичний аудит axe-core за правилами WCAG 2 A/AA та WCAG 2.1 AA
  не виявив порушень на ширинах 375, 768 і 1440 px та в перевірених станах
  відкритого меню. Це не замінює повну перевірку зі скринрідером.
- `npm run build`, `npm run format:check` та `git diff --check` проходять.

## Виправлення на фінальному етапі

- Затемнено другорядний текст у How it works та Reviews до #707070:
  попередній #858585 на #fbfbfb мав контраст близько 3.56:1 замість 4.5:1.
- Додано посилання Skip to main content, яке з’являється при фокусі клавіатури.
- Виправлено команду preview: її базовий шлях тепер збігається з production-збіркою.
- Оновлено сумісні залежності без примусової зміни основної версії Vite.

## Що ще потрібно визначити

- Спосіб отримання заявок: сервер або зовнішній сервіс поки не підключено.
- Потребу в окремій модальній заявці з ТЗ: зараз форма розташована в секції за Figma.
- Адреси профілів у соцмережах: зараз посилання ведуть на головні сторінки платформ.
- Зміст Privacy Policy та поведінку Cookie settings: у Footer це поки текст.
- Міграцію інструментів: npm audit залишає 2 повідомлення — Vite (high)
  та esbuild (moderate). Для їх усунення потрібен перехід на іншу основну версію Vite.
- Перевірку на реальних iOS/Android-пристроях, у Firefox/Safari та після
  фактичної публікації GitHub Pages. У цьому середовищі перевірявся Chromium.

Форма підписки не додається за прямим рішенням користувача.
Desktop починається з 1280 px за макетом Figma та рішенням користувача.
Після зміни перевірено ширини 1279, 1280 та 1281 px, перемикання зображень,
кількість колонок, закриття відкритого меню при переході на desktop
та автоматичний аудит доступності на 1280 px — перевірки пройшли.
Карусель відгуків і favicon — погоджені доповнення до макета.
